# US Stock Analysis Skill (美股三維財務分析 Skill)

美股上市公司的三維財務分析儀表板生成工具。

## 功能特點
- 📊 **自動抓取**：透過 yfinance 抓取任何美股 (如 NVDA, AAPL, TSLA, MSFT, GOOGL) 的最新三年完整財報。
- 💰 **三維指標計算**：
  - 經營分析 (Revenue, Gross Margin, R&D, Op Margin)
  - 獲利分析 (Net Income, EPS, ROE, ROA)
  - 財務健全度 (Cash & Equivalents, Current Ratio, Debt Ratio, Free Cash Flow)
- 🎨 **互動 HTML 儀表板**：自動生成包含 Chart.js 動態圖表、KPI Cards、Insight Boxes 與 Data Tables 的三分頁 HTML 檔案。

## 使用方式
直接對 Antigravity Agent 輸入：
- `幫我分析美股 NVDA`
- `幫我看 AAPL 財報`
- `分析 TSLA`
